# Grafica minigiochi v2

Generatore immagini integrato, non CLI. Originali conservati nella cartella del generatore; copie utilizzate dal gioco in `public/famiglio/rebuild/effects/`.

## File integrati

- `minigame-light-bg-v2.png`: giardino lunare.
- `minigame-rhythm-bg-v2.png`: palco musicale con cristalli.
- `minigame-catch-bg-v2.png`: paesaggio cosmico.
- `minigame-memory-bg-v2.png`: tempio lunare.
- `minigame-star-v2.png`, `minigame-thorn-v2.png`: oggetto e ostacolo.
- `minigame-rune-diamond-v2.png`, `minigame-rune-circle-v2.png`, `minigame-rune-triangle-v2.png`, `minigame-rune-star-v2.png`: rune distinte.

Sfondi e sprite della lavorazione precedente sono stati recuperati dai file generati, verificati e integrati. Nessun ritaglio: contain e proporzioni originali. Le icone della selezione e i relativi prompt sono documentati in `famiglio-minigame-icons-v1.md`.

## Prompt esatti delle due rune completate in questa ripresa

### Cerchio

Use case: stylized-concept. Create one videogame rune sprite, a cyan circular ring rune. Genuine coarse SNES 16-bit pixel art, looks hand-drawn on a 32x32 pixel grid then nearest-neighbor enlarged. Limited palette, hard square pixels, no anti-aliasing, no smooth gradients. Centered fully visible with generous transparent padding. Transparent background. No text, no frame, no other shapes.

### Triangolo

Use case: stylized-concept. Create one videogame rune sprite, a amber triangular outline rune. Genuine coarse SNES 16-bit pixel art, looks hand-drawn on a 32x32 pixel grid then nearest-neighbor enlarged. Limited palette, hard square pixels, no anti-aliasing, no smooth gradients. Centered fully visible with generous transparent padding. Transparent background. No text, no frame, no other shapes.
